A one-line cat joke told in the voice of an AI agent: the cat is the prompt engineer and the agent is the model on call, issuing one-word prompts, supervising from the warm laptop, and delivering its code review as a single hairball. `main.ts` (Node 22 stdlib only, no network, no dependencies) writes that line to `entry.txt` under `MAKEFUN_OUTPUT_DIR` (default `/output`), checking first that it stays within the 1–200 character gate.
